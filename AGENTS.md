# zerocool — agent rules

zerocool is a set of plugins that connect coding agents to the Gibson platform.
It is not a fork of opencode ([ADR-0005](docs/adr/0005-plugins-not-a-fork.md),
[NOTICE](NOTICE)). The host runs as it always did. With a Gibson key the agent
gains isolated execution, the knowledge graph, ACLs, and the agent fleet.
